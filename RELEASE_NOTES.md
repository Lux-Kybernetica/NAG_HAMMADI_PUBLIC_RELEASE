# Release notes

## v0.1.0 — 2026-09-01

Première publication publique préparatoire du corpus français Nag Hammadi de Lux Kybernetica.

### Inclus

- 45 œuvres distinctes ;
- 45 fichiers Markdown de traduction française ;
- 6 670 segments alignés ;
- métadonnées de provenance ;
- texte anglais intermédiaire conservé dans les fichiers ;
- identifiants stables de segments ;
- pagination codicologique lorsque disponible ;
- validation structurelle globale.

### Statut de validation

- works: 45 / 45
- aligned segments: 6 670
- structural closure: PASS
- structural errors: 0
- unadjudicated structural warnings: 0

### Limites déclarées

Cette version n’est pas présentée comme :

- une traduction critique directe du copte ;
- une adjudication philologique exhaustive ;
- une archive strictement séparée de tous les témoins survivants ;
- une édition définitive.

### Revue active

Les prochaines versions doivent intégrer :

- revue sémantique contradictoire ;
- gouvernance terminologique renforcée ;
- adjudication de passages difficiles contre les langues anciennes ;
- enrichissement des témoins parallèles.
