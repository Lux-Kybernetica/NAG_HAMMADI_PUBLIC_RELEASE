# Contribuer

Les corrections sont bienvenues lorsqu’elles sont **traçables et argumentées**.

## Pour signaler une traduction discutable

Indiquez :

1. l’œuvre ;
2. le témoin ;
3. le `TARGET-ID` ;
4. le passage anglais concerné ;
5. le français actuel ;
6. le problème identifié ;
7. la correction proposée ;
8. les éléments de preuve disponibles.

Pour une proposition philologique, ajoutez si possible :

- forme copte / grecque pertinente ;
- transcription ou édition consultée ;
- référence bibliographique ;
- numéro de page ou section.

## Priorités

Les contributions les plus utiles concernent :

- contresens ;
- négations ;
- référents ;
- agent / patient ;
- termes techniques ;
- restitutions et portée des crochets ;
- témoins parallèles ;
- références philologiques.

## Ce qu’il faut éviter

- lisser une phrase uniquement parce qu’elle paraît étrange ;
- remplacer automatiquement tous les termes identiques par une traduction unique ;
- effacer une lacune ;
- harmoniser silencieusement deux témoins ;
- modifier la géométrie `[ ]`, `< >`, `( )` sans justification.

La fidélité documentaire prime sur l’élégance.
