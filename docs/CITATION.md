# Citer le corpus

Citation courte recommandée :

> **Lux Kybernetica. _Nag Hammadi Library — Corpus français de recherche_. Version 0.1.0, 2026.**

Pour citer un passage précis, ajouter :

- l’œuvre ;
- le témoin ;
- le `TARGET-ID` ;
- la version du dépôt ou le commit Git.

Exemple :

```text
Lux Kybernetica, Nag Hammadi Library — Corpus français de recherche,
NHC II,5, TARGET-ID NHC-II-5::FR-LK::Pxxxx,
version 0.1.0 (2026).
```

L’identifiant de segment est préférable à un simple numéro de paragraphe, car il reste exploitable par les outils du corpus.
