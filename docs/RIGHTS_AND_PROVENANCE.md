# Droits et provenance

## Sources anglaises

Le corpus de recherche amont utilise principalement les traductions anglaises de **Samuel Zinner**, éditées par **Mark M. Mattison**, publiées via Luminescence / Other Gospels.

Le projet d’origine indique que ces traductions ont été **placées dans le domaine public** et peuvent être réutilisées.

Référence canonique indiquée par le projet amont :

https://www.luminescence-llc.net/nag-hammadi

Les fichiers français conservent les informations de provenance pertinentes dans leur front matter, notamment le traducteur anglais, l’éditeur, le fichier source et son SHA-256.

## Sources protégées

Les éditions critiques et traductions modernes protégées, notamment celles publiées chez Brill ou par d’autres éditeurs savants contemporains, ne sont pas automatiquement redistribuées.

Une ressource peut avoir été consultée comme référence bibliographique sans faire partie du payload public.

## Traduction française

La traduction française constitue une couche originale produite dans le cadre du projet Lux Kybernetica.

**La présente documentation ne constitue pas à elle seule une concession de licence ouverte sur cette couche française.**

Voir `LICENSING.md`.

## Principe

Le statut de droits d’un témoin, d’une traduction ou d’un ouvrage critique doit être déterminé séparément.

Une ressource accessible en ligne n’est pas automatiquement libre de redistribution.
